// Calibration for 2–3 YOE GenAI Role

Calibrate your focus across the three core tiers of senior technical evaluation:

1. Must Answer (Screening Gate)

Python async/GIL, FastAPI dependency injection, SQL MVCC & B-Tree vs GIN, Docker multi-stage builds, self-attention Q/K/V intuition, basic RAG chunking and embeddings.

2. Portfolio Proof (Your Builds Are The Answer)

Defend your code with architecture diagrams, latency metrics, token cost tracking, Ragas eval numbers, failure cases, and cloud infrastructure choices (Azure vs AWS).

3. Senior Stretch (True Differentiators)

HNSW graph indexing math, KV cache VRAM calculations, PagedAttention in vLLM, Model Context Protocol (MCP) servers, and multi-tenant agent execution sandboxing.

// 10 Non-Negotiable Rules for Success

  1. One-Command Run: Every project must have a working Dockerfile or live URL. Zero notebook-only projects.
  2. Defend Every Line: If you can't explain why a line of code exists, rewrite it until you can.
  3. Start Applying at Week 24: Interviews teach you faster than passive tutorials what gaps remain.
  4. 2:1 Ratio: For every 1 hour reading documentation, spend 2 hours actively writing code.
  5. Trace Every LLM Call: If you cannot show latency, token usage, and cost per request in Langfuse, it's not production code.
  6. Continuous DSA from Day 1: Solve 2-4 problems weekly. Do not wait for Week 30 to cram coding screens.
  7. Threat Model in README: Document the prompt injection and data exfiltration defense for every AI repo.
  8. Document Architectural Trade-Offs: Write WHY you picked pgvector over Pinecone or Azure over AWS.
  9. No Scope Creep: Follow the cut list strictly until your core roadmap is complete.
  10. Accountability Over Motivation: Log your planned vs actual study hours every single week.

// The Cut List: Ignore Until You Land The Job

Do not waste your 1.5–2 hours/day on these distractions during this 8-month switch. Focus exclusively on the backend + GenAI core:

Kubernetes / K8s Cluster Admin Apache Spark / Hadoop React / Next.js Frameworks (Use Streamlit) Training Foundation LLMs from Scratch 300+ LeetCode Grind Long 40-Hour Udemy Courses AWS / Azure Solutions Architect Certifications Fine-Tuning 70B Parameter Models
